# Source package — Data Modeling

This folder groups the Phase 1 deliverables by topic so it can be packaged as the source submission.

## Folder contents

- `01_data_understanding/`: source inventory, field dictionary, data profiling notes, results, and profiling script.
- `02_requirements_and_metrics/`: analysis grain, metric definitions and decisions, and requirements traceability.
- `03_dimensional_model/`: conceptual, logical, and physical model artifacts, including editable diagrams and previews.

The editable diagram files are included alongside their rendered previews. The profiling script can be rerun when the source data described in the project README is available.

For submission, zip this folder and name the archive `<MaNhom>_Src.zip`.
